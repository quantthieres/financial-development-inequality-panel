# Figures

This folder stores figures generated by `scripts/panel_credit_gini_analysis.R`.

## Available Figures

| File | Description |
|---|---|
| `raw_correlation_credit_gini.png` | Scatter plot of lagged private credit (% GDP) vs. Gini index — pooled correlation, no country fixed effects |
| `fixed_effects_credit_gini.png` | Scatter plot after demeaning by country — shows within-country variation between credit and inequality |
| `static_model_coefficients.png` | Comparison of the `credito_lag` coefficient across static models (Pooled OLS, FE 1-way, FE 2-way, RE) |
| `local_projections_irf.png` | Cumulative impulse response of Gini to a credit shock via panel Local Projections (90% CI, Driscoll-Kraay errors) |

## How to Save Figures from the Script

The script currently renders plots to the R graphics device but does not save them automatically.
To export, wrap each `ggplot()` call with `ggsave()`:

```r
p <- ggplot(df, aes(x = credito_lag, y = gini)) + ...
ggsave("outputs/figures/raw_correlation_credit_gini.png",
       plot = p, width = 7, height = 5, dpi = 300)
```

For base R plots:

```r
png("outputs/figures/static_model_coefficients.png", width = 700, height = 500)
plot(...)
dev.off()
```
